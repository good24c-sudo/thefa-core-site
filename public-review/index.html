BEFORE YOU START

여기에 소개한 제품은 모두 사용할 수 있나요?

개발한 영역을 소개하는 자체 개발 사례입니다. 기능마다 화면 개발, 연동 검증, 사용 가능한 범위가 다릅니다. 실제 사용 범위는 도입 상담에서 확인합니다.

체험 화면은 실제 고객 데이터인가요?

모든 공개 체험 화면은 가상 예시입니다. 실제 고객 정보나 고객의 사업 성과를 사용하지 않습니다.

우리 회사의 도구와 연결할 수 있나요?

필요한 업무와 현재 사용하는 도구를 알려주시면 연결 가능한 범위와 확인할 항목을 함께 검토합니다.

기존 고객 서비스는 어디에서 사용하나요?

공개 홈페이지 수정 방향

가치는 더 잘 보이게,
공개 범위는 신중하게.

자체 개발 자산을 제품 사례로개발한 영역을 제품군별로 소개하고, 화면 개발·연동 검증 상태를 구분합니다.
내부 설계 설명을 고객 경험으로제품의 사용 목적과 결과를 보여주며 상세한 내부 구성과 운영 정보는 제외합니다.
공개 체험은 가상 데이터로사례별 요청과 결과를 살펴볼 수 있습니다. 실제 고객 기록이나 고객 성과는 사용하지 않습니다.
상세 자료는 도입 상담으로도입 범위와 필요한 자료는 상담 과정에서 확인합니다.

현재 운영 사이트·고객 서비스·저장소 권한은 변경하지 않은 로컬 수정 데모입니다. 고객 서비스 개발은 별도 프로젝트 방의 범위입니다.
