AVA

나에게 맞는 AI 동료

현재는 AVA 설정 초안입니다. 실제 기억 수집, 대리 실행, 권한 부여는 별도 동의와 실행 연결을 필요로 합니다.

LOCAL FIRST · SMART COST

로컬 AI · PC 연결

내 PC 자원을 활용하고 꼭 필요할 때만 외부 AI를 사용하는 방향으로 준비합니다.

▣

내 PC는 그대로, 필요할 때만 연결

로컬 AI·개발 도구를 사용하면 일부 작업의 외부 API 비용을 줄일 수 있습니다. PC 연결은 사용자 승인과 별도의 안전한 연결 절차가 필요합니다.

로컬 AI 연결미연결이 브라우저는 PC에 자동 접근하지 않습니다.
외부 AI 비용측정 전실제 사용 기록 기준으로만 표시합니다.
검증된 비용 절약측정 전추정 절감액은 실제 절감액으로 표시하지 않습니다.

고객용 로컬 설정 안내

Windows 설정 도구와 로컬 AI 모델 준비는 선택 사항입니다. 이미 설치한 모델과 개발 파일을 제거하거나 바꾸지 않습니다.

01PC에서 설치 항목과 기존 자원 확인
02필요한 로컬 AI 모델만 사용자 승인으로 선택
03안전한 PC 연결·권한·비용 상한 확인
04로컬 가능 작업 우선, 부족하면 승인을 받고 클라우드 사용
로컬 PC 설치·연결은 현재 비활성화 상태

실제 고객용 PC 자동 연결은 아직 제공하지 않습니다. 설치 파일 다운로드와 연결 성공은 별개입니다.
