크레딧 차감 정책

1크레딧 = 1원 · 무료 체험 10회는 별도로 유지됩니다.

조회 중
원가 500원일 때 고객 차감1,000 크레딧 = 1,000원

AI가 보고한 사용량과 적용 단가·환율로 원가를 계산하고, 배율을 곱한 최종 금액을 1원 단위로 올림합니다. 표시 금액은 부가세 포함입니다. 공급사 청구서 대사 전 원가이며, 사용 근거가 부족한 유료 요청은 금액 확인 상태로 보존합니다.

저장한 정책은 이후 시작되는 요청에 적용됩니다. 기존 사용 내역과 실행 중인 요청의 금액은 바뀌지 않습니다. 월 제공량 변경은 결제 연결 후 새로 부여되는 이용권에 적용할 설정이며, 저장만으로 고객 잔액이 생기지는 않습니다.

현재 정책을 확인하고 있습니다.
