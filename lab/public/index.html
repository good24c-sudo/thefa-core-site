상태 표기의 의미
REAL
실제 외부 시스템에서 수행됨. 이 Lab은 외부 실행을 제공하지 않습니다.
LOCAL
이 PC의 코드 또는 기존 Local AI가 실제로 수행함.
MOCK
기능 흐름 확인을 위한 모의 자원 / 모의 실행.
PLANNED
향후 지원할 연결이며 아직 실행할 수 없음.
DISCONNECTED
연결이 없거나 사용 가능함을 확인하지 못함.
